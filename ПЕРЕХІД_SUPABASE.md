# Перехід «Моєї бібліотеки» з Google-таблиці на Supabase

Погоджено 14.11.2026 (варіант В з документа https://claude.ai/artifact/MeiYnQtVh1i4AjxYsac8iM).

## Рішення користувачки
- Одне джерело правди про книги — база Supabase. Редагування лише в додатку.
- Каталог видань за ISBN наповнюється сам з інтернету (MEGOGO, Goodreads, книгарні).
- Google-таблиця «Книги» — щонічна резервна копія для перегляду. Меню таблиці («Код.gs») і вікно статистики не переносимо.
- Безкоштовний тариф, без картки. Ключі (бот, Gemini, НП) вона сама вписує в Supabase → Edge Functions → Secrets; у чат і репо — ніколи.

## Архітектура
- `supabase/migrations/` — структура бази (`books`, `catalog`, `series`, `log`, `kv`). RLS увімкнено без політик: сайт ходить лише через edge-функцію.
- Edge-функція `api` (TypeScript): ті самі назви функцій, що й `doPost` у `LibApp.gs` (`{fn, args, initData, key}`), перевірка ключа `?k=` / підпису Телеграму. Сайт змінює лише адресу в `config.js`.
- Edge-функція `bot` — webhook Телеграму (відповідь миттєва, без щохвилинного опитування).
- Розклад (pg_cron → edge-функції): нагадування ~9:00, нічне доповнення каталогу й обкладинок ~3:00, Нова пошта щогодини, новини серій у понеділок, нічний експорт у Google-таблицю.
- Автодеплой: GitHub Actions (`supabase db push`, `supabase functions deploy`) із секретом `SUPABASE_ACCESS_TOKEN` у налаштуваннях репозиторію.

## Розгортання функцій
Функції розгортаються через MCP маленьким `index.ts`, який імпортує код із репозиторію, закріплений на коміті:
`import "https://cdn.jsdelivr.net/gh/doragolum/library@<sha>/supabase/functions/<name>/index.ts";` (спершу коміт і push).
