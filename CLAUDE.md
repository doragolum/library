# «Моя бібліотека» — інструкції для Claude

Особистий вебдодаток для обліку книг, бажанок і замовлень. Користувачка одна, спілкування й інтерфейс українською. Пояснюй просто, без жаргону: вона часто працює з телефона й сама вставляє код в Apps Script.

## Навіщо додаток (пріоритети)
1. **Зареєструвати бажанку чи замовлення за секунди**: скриншот анонсу/замовлення або текст → готова картка → «Зберегти». Раніше це робив ChatGPT.
2. **«Отримала» → книга в бібліотеці** з автозаповненням (жанр, серія, полиця), перевіркою дублів, також для цілого замовлення.
3. **«Що почитати?»**: опитувальник (одиночна/серія → жанр/тропи/настрій → мова → обсяг), недочитані серії.
4. Статистика, досягнення, полиці, план читання — бонус, не основний інтерфейс.

## Архітектура
- **Дані:** Google-таблиця «Книги». Листи: `Облік бібліотеки`, `Бажанки`, `Серії`, `Каталог книг`, `Продані`, `Лог`.
- **Сервер:** Apps Script, прив'язаний до таблиці.
  - `LibApp.gs` — код додатку. Усі назви з префіксом `lb` / `LB_`. API для сайту — `doPost` (`{fn, args, initData, key}`, дозволені лише функції зі списку `API`).
  - Скрипт меню таблиці (`addBook`, `updateLibrary`, `sortLibrary`, `renumberBooks`, `updateSeriesInfo`, `syncPublishers`, `sortWishlist` тощо). `LibApp` викликає ці функції, але не змінює їх.
  - Код Нової пошти (`np*`). **Не чіпати.**
- **Сайт:** GitHub Pages — https://doragolum.github.io/library/ (цей репозиторій). Відкривається за особистим посиланням `?k=…` або як Телеграм-міні-додаток.
- **Телеграм-бот:** опитування щохвилини (`lbBotPoll`), пошук книг, скриншот → картка з кнопками «У бажанки / Замовила», нагадування про релізи.
- **Джерела даних про книги:** MEGOGO Books (перше), Книгарня Є (запасне, серія й дата), обкладинки — Goodreads / Google Books.
- **Gemini** (лише безкоштовний тариф): скриншоти, жанри, тропи. Порядок моделей у `lbGeminiModels_()` з перемиканням при 404/429/503. Пошук Google через Gemini на безкоштовному тарифі **недоступний** (429), тому «Новини серій» беруться з MEGOGO.

## Структура файлів репозиторію
Корінь репозиторію — це сайт на GitHub Pages. Папка `apps-script/` — копії коду з Apps Script, щоб Claude їх бачив; сама вона на сайт не впливає, а в Apps Script код вставляється вручну.

**Сайт (корінь):**
- `index.html` — увесь сайт одним файлом: вигляд, стилі й логіка (вкладки, картки книг, бажанки, «Що почитати?», полиці, статистика). Дані бере через `fetch` на адресу з `config.js` (запит `{fn, args, initData, key}` до `doPost`). Головний файл для змін інтерфейсу.
- `config.js` — одна змінна `window.LB_API_URL` — адреса розгортання Apps Script (`…/exec`). Міняти лише якщо змінилася адреса розгортання (при «Нова версія» вона та сама).
- `README.md` — короткий опис для GitHub.
- `robots.txt` — забороняє пошуковикам індексувати сайт.
- `.nojekyll` — порожній файл, щоб GitHub Pages віддавав файли як є, без обробки Jekyll.
- `CLAUDE.md` — цей файл з інструкціями.

**Apps Script (`apps-script/`):**
- `LibApp.gs` — сервер додатку (префікс `lb` / `LB_`). Основні частини:
  - сторінка й API: `doGet` (сторінка `LibPage` всередині Apps Script), `doPost` (список дозволених функцій `API` для сайту), перевірка доступу `lbAuth_` (ключ `?k=` або підпис Телеграму);
  - читання й запис таблиці: `lbReadAll_`, `lbApiUpdate` / `lbApiSave`, `lbApiAddBook`, `lbApiAddWish`, `lbApiDeleteWish`, `lbApiDeleteBook`, `lbOrderSave_` (замовлення → бажанки), журнал `lbLog_`;
  - Gemini: `lbGemini_`, `lbGeminiModels_`, розпізнавання скриншотів `lbApiOcr` / `lbApiAi`, жанри `lbApiGenre`, тропи `lbApiTropes`;
  - дані про книги: MEGOGO (`lbFromMegogo_`), Книгарня Є (`lbFromBookYe_`), обкладинки Goodreads / Google Books / Open Library (`lbFillCovers`), автозаповнення порціями `lbAutoFill`;
  - «Новини серій»: `lbSeriesNews`, `lbApiNews` (лише пропозиції, зберігаються в `LB_NEWS`);
  - Телеграм: `lbTelegramConnect`, `lbBotPoll`, кнопки й фото в боті;
  - нагадування: `lbInstallReminders`, `lbDailyReminders` (релізи, «ще не відправили», тиждень/місяць, Київ);
  - нічні роботи: `lbNightly` (сортування, `lbCleanWish_`, `lbWishOnSale_`, обкладинки);
  - тести без змін у таблиці: `lbTestNews`, `lbTestGemini`, `lbTestSources`, `lbTestCover`, `lbTestReminders`.
- `LibPage.html` — та сама сторінка для відкриття прямо з Apps Script (`doGet`). Це **старіша копія** `index.html`: останні зміни інтерфейсу є лише в `index.html`. Головна адреса — сайт на GitHub Pages.
- `Код.gs` — скрипт меню таблиці (`onOpen`, `addBook`, `updateLibrary`, `sortLibrary`, `sortWishlist`, `renumberBooks`, `updateSeriesInfo`, `syncPublishers`, `sellBooks`, `updateCatalog`, `cleanWishlist`, `findMissingSeriesBooks`, `transferWishlistToLibrary`, `showStatistics` тощо). `LibApp` викликає ці функції, але не змінює їх.
- `Statistics.html` — вікно статистики в самій таблиці (відкриває `showStatistics` з `Код.gs`).
- `NovaPoshta.gs` — Нова пошта: `npUpdate` (щогодини перевіряє ТТН з колонки O і пише статус у P–S), `npInstall`, `npSelfTest`. **Не чіпати.**
- `NpWishlistStatus.gs` — переносить статус НП у колонку E бажанок (Створено ТТН → Відправлено → Доставлено → В бібліотеці); викликається з `npUpdate`. **Не чіпати.**
- `NpGmailProbe.gs`, `NpIncomingProbe.gs` — разові перевірки (нічого не записують, лише журнал): чи можна знаходити ТТН у листах Gmail і серед вхідних накладних НП. Заготовка для задачі «Імпорт замовлень із Gmail».

Під час релізу сервера до репозиторію додаються `LibApp.gs.txt` і `ОНОВЛЕННЯ_vN.md` (див. нижче).

## Як випускати зміни
- **Сайт:** коміт у цей репозиторій → GitHub Pages оновлюється сам.
- **Сервер:** Claude не може розгорнути Apps Script. Для кожного релізу:
  1. поклади повний `LibApp.gs.txt` і коротку інструкцію `ОНОВЛЕННЯ_vN.md`;
  2. користувачка вставляє код у `LibApp.gs` і робить **Розгорнути → Керувати розгортаннями → ✏️ → Нова версія → Розгорнути**;
  3. разові функції (міграції, тести) — окремим кроком з поясненням, що вони роблять.
- Перед публікацією показуй, що змінилося, і чекай «так». Тестові функції (`lbTest*`) нічого не змінюють і пишуть у журнал.

## Правила
- **Ключі й токени** тільки у Властивостях скрипту, ніколи в коді, репозиторії чи чаті.
- **Таблиця:** колонки шукаються за заголовком, не за буквою. Не видаляти й не перейменовувати колонки. Нові колонки — лише в кінець і лише після «так». Масові зміни даних — спершу список змін на погодження.
- **Бажанки, колонки E (Статус), N (Номер замовлення), O (ТТН), P–S (статус НП)** використовує код Нової пошти — не змінювати структуру.
- Колонки «Завершена?» і «Повний переклад укр» в `Облік бібліотеки` не видаляти.
- Запис у таблицю — під `LockService` (з Новою поштою можливі одночасні запуски). Рядок шукати заново за автором і назвою: таблицю сортують щоночі.
- **Без оплат:** не підключати платні тарифи, картки чи API з оплатою без явної згоди.
- Gemini помиляється з фактами: дані з інтернету показувати з джерелом і лише як пропозицію, яку користувачка підтверджує.
- Нічого не записувати в таблицю автоматично там, де можна помилитися (новини серій, жанри, тропи) — лише пропозиції з кнопкою підтвердження.

## Властивості скрипту
`LB_TG_TOKEN`, `LB_TG_APP_URL`, `LB_PAGE_URL`, `LB_TG_CHAT_ID`, `LB_TG_USER_ID`, `LB_WEB_KEY`, `GEMINI_API_KEY`, `GEMINI_MODEL` (необов'язково), `NP_API_KEY`. Службові стани: `LB_GOALS`, `LB_SHELF_MARKS`, `LB_NEWS`, `LB_AV_TRIED`, `LB_AV_STATE`, `LB_COVER_TRIED3`, `LB_BOT_PENDING`, `LB_TG_OFFSET`.

## Тригери
`lbDailyReminders` (щодня ~9:00), `lbNightly` (~3:00: сортування, прибирання бажанок, «Є у продажу», обкладинки), `lbBotPoll` (щохвилини), `lbSeriesNews` (понеділок ~5:00), `lbAutoFill` (порціями, сам себе продовжує), `npUpdate` (щогодини, Нова пошта).

## Значення в таблиці
- Статус читання: прочитано · не читала · читаю · закинула.
- Наявність: бібліотека · Київ · продана · подарована · позичена · на продаж · на розподілення. «Київ» — книги, що лежать у Києві й приїжджають посилкою.
- Статуси бажанок (по порядку): Хочу купити · Докупити серію · На майбутнє · Замовлено · Створено ТТН · Відправлено · Доставлено · В бібліотеці.
- Наявність бажанки: Є у продажу · Анонс · Передзамовлення · Немає у продажу · Не видана.
- Ціна 0 — безкоштовна книга (акція).
- Додаткові колонки: ISBN, Обкладинка, Дата покупки, Дата початку, Дата прочитання, Оцінка, Кому/Коли позичила, Повернути до, Посилка з Києва, Планую читати, Поточна сторінка, Тропи, Враження.

## Відкриті задачі
- Імпорт замовлень із Gmail (скрипт сам знаходить листи магазинів, пропозиції на підтвердження).
- Масове заповнення тропів через Gemini з підтвердженням.
- Приватність: скриншоти замовлень з адресою/телефоном не надсилати в Gemini (безкоштовний тариф може використовувати дані), лише анонси.
